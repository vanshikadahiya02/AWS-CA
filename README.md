# AWS-CA
aws ca 1 assisment gym web

GYM 9

>Objective
A simple, responsive gym and fitness website (MSE Problem Statement 6) that shows workout plans, fitness programs, membership plans and health information.

>Features
- Responsive layout (works on mobile and desktop)
- Fitness programs section
- Workout plans loaded from an XML file, with Beginner / Intermediate / Advanced filter
- BMI calculator
- Membership plans loaded from the XML file, with "Choose" button
- Health tips (click to show/hide)
- Contact form with validation

>Technologies Used
- HTML
- CSS
- JavaScript (basic)
- XML (stores workout plans and membership data)
